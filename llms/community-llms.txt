- [Add / Remove Member from Subcommunity](https://developer.community.com/reference/change-community-membership.md): You can either pass in the subcommunity ID (`tag_id`) or the `tag` name. If you provide both, `tag_id` takes precedence.
- [Create a Subcommunity](https://developer.community.com/reference/tag-create.md)
- [Delete a Subcommunity](https://developer.community.com/reference/tag-delete.md): You can either pass in the subcommunity ID (`tag_id`) or the `title`. If you provide both, `tag_id` takes precedence.
- [Update a Subcommunity](https://developer.community.com/reference/tag-update.md): Similar as the tag_create operation, this will update the desired tag (Subcommunity), identified by the provided `tag_id`.  This is a delta-update, i.e., omitted fields will not modify the Subcommunity. I.e.: If you only want to update the tag's `title` but leave color and description the same, only pass the `tag_id` and the `title`, so that the rest will stay the same.
- [Add / Remove keywords from Subcommunity](https://developer.community.com/reference/tag-keyword-modify.md): You can either pass in the subcommunity ID (`tag_id`) or the `title`. If you provide both, `tag_id` takes precedence.
